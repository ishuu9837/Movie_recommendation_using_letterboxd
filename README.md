# MRS by Letterboxd 6.0
Vite + React 18 + TypeScript. Static deploy (Vercel/Cloudflare/Netlify), no backend.
`npm i && npm run dev` · `npm test` · `npm run build` (output: dist/). `npm run data -- <path/to/old/catalogue.js>` regenerates public/catalogue.json.

Previous v5 design, security and deployment reports are preserved under `docs/archive/v5/`; their verification results describe v5, not this replacement implementation. `PROJECT_HISTORY.log` records the migration.
